# 知练 CoachMind v1.0

## 视频分析
- 选择运动员：在第一帧点一下运动员，金色框跟着他走，只把框里的画面放大后识别。人很小、画面里有其他人时识别率大幅提高
- 两人交叉时按运动方向预测，不会跟错人
- 自动识别重复帧：屏幕录制、网络视频会改按真实帧率计算并提示
- 新增步频（摆腿周期法）：脚的落点看不清时也能测出跑步节奏

## 设计
黑色、古金、象牙白；宋体标题与 Didot 数字；封面与项目卡片支持真人照片（见 img/照片说明.md），也可以在 App 里点“更换封面照片”用自己的照片

## 训练计划
新增 5 个项群的计划库：快速力量性、耐力性、表现难美性、隔网对抗性、同场对抗性。运动员档案里选项目后，计划、测试指标、伤病预防重点都会按该项群生成
