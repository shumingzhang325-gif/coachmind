# 知练 CoachMind v0.3

## 这一版新增

**运动员画像**（首页 → 运动员）
- 档案：身高、体重、100 米成绩、目标成绩和日期、每周训练次数、测试成绩
- 目标模型：用短跑单指数速度模型从目标成绩倒推需要的最高速度、30 米成绩，以及步长步频组合
- 七维能力雷达：速度、加速、速度耐力、力量、爆发力、技术、恢复，100 分 = 达到目标模型
- 与优秀运动员对比：博尔特最高速段（Čoh 等 2018）
- 多学科分析：运动训练学、生物力学、生理学、力量与体能、营养、伤病预防、恢复、心理，每条都附文献或标明“经验值”

**训练计划**（运动员 → 计划）
- 从目标日期倒推：一般准备期 → 专项准备期 → 赛前期 → 调整比赛期
- 每 4 周一个调整周，阶段末安排测试
- 能力短板和视频诊断结果自动变成训练重点
- 录入新测试成绩后，画像和计划自动更新

**每日状态**（运动员页顶部“今天”）
- 睡眠、疲劳、酸痛、训练 RPE 和时长
- 红黄绿状态灯，并给出当天训练怎么调整

**视频分析改进**
- 自动纠正左右腿标签互换（上次识别出 0 次触地的可能原因之一）
- 手动标记触地：自动识别失败时，教练逐帧标记，结果立即重算
- “识别过程”图：显示算法为什么认为是或不是触地，截图发我可以排查
- 与目标、博尔特对比条
- “把诊断重点加入训练计划”

## 更新方法

把下面这些文件上传到 GitHub 仓库，覆盖旧版本（之前下载的 5 个离线文件不用动）：
`index.html` `app.js` `engine.js` `coach.js` `sw.js` `manifest.webmanifest` `icon-180.png` `icon-192.png` `icon-512.png`

**注意新增了 `coach.js`，一定要上传。**

手机上打开后如果还是旧界面，在 Safari 里下拉刷新一次。

## 第一次使用建议的顺序

1. 首页 → 添加运动员 → 在“档案”里填成绩、目标、日期
2. 录入测试：30 米行进间跑、30 米起跑、立定跳远、深蹲 1RM（至少前两项）
3. 看“画像”和“计划”
4. 拍一段途中跑视频分析，分析结果会自动进入画像的“技术”维度
5. 之后每天在“今天”打卡

## 说明

- 标注“经验值”的参考目标（深蹲 2 倍体重、立定跳远 3 米、触地 0.10 秒等）可以在档案里修改，建议请老师审核
- 训练计划是模板建议，需要教练审核后使用
- 数据只存在当前设备的 Safari 里；重要数据请定期在首页“导出表格”
